# 01. 게임 비전과 개발 전략

## 1. 게임 비전

### 한 줄 정의
> "어둡고 묵직한 세계에서, 몬스터를 쓸어담고 전리품으로 캐릭터를 끝없이 성장시키는 싱글플레이 핵앤슬래시 ARPG"

### 핵심 재미 (Core Fun)
디아블로2가 20년 넘게 사랑받는 이유를 세 가지 축으로 재현합니다.

1. **전투의 손맛** — 쿼터뷰 시점에서 다수의 적을 스킬로 쓸어담는 타격감
2. **파밍의 중독성** — 낮은 확률의 강력한 아이템(유니크, 룬)을 노리는 반복 플레이
3. **빌드의 자유** — 스킬트리 + 아이템(룬워드) 조합으로 만드는 나만의 캐릭터

### 디자인 필러 (Design Pillars)
모든 설계 결정은 아래 4가지 필러에 비추어 판단합니다.

| 필러 | 의미 | 판단 기준 예시 |
|------|------|--------------|
| **선택의 무게** | 스킬 포인트/스탯 투자는 쉽게 되돌릴 수 없다 | 무제한 리스펙 대신 제한된 리스펙 기회 제공 |
| **전리품이 곧 성장** | 레벨보다 아이템이 캐릭터 파워의 중심 | 레벨 상승 자체의 파워 비중을 40% 이하로 유지 |
| **어두운 판타지** | 밝고 가벼운 톤 배제, 묵직한 세계관 | 아트/사운드/UI 전반의 톤앤매너 통일 |
| **반복이 즐거운 루프** | 같은 구간을 다시 돌아도 보상이 기대되는 구조 | 난이도 단계 + 정복자 + 랜덤 아이템 드랍 |

## 2. 1차 범위 (Scope)

### 포함 (In Scope)
- **싱글플레이 전용** (오프라인, 로컬 세이브)
- **캐릭터 2종**: 근접 전사 / 원소 마법사
- **스킬트리**: 캐릭터당 3계열 × 8~10개 스킬, 시너지 시스템
- **아이템 시스템**: 등급(일반~유니크), 접사(Affix) 랜덤 생성, 소켓
- **룬워드**: 룬 12종 이상, 룬워드 레시피 10종 이상
- **정복자 시스템**: 만렙(50) 이후 무한 성장 보드
- **캠페인**: 1개 액트 분량(3~4개 지역, 보스 2종) + 반복 파밍 콘텐츠
- **난이도**: 노말 → 악몽 → 지옥 3단계

### 제외 (Out of Scope — 2차 이후)
- 멀티플레이/온라인 (단, 시스템 설계는 확장 가능하게)
- 3번째 이후 캐릭터 클래스
- 거래/경제 시스템
- 하드코어 모드, 래더/시즌

### 범위 관리 원칙
- 콘텐츠 양(맵, 몬스터 종류)보다 **시스템 완성도**를 우선한다.
- "액트 5개 만들기"가 아니라 "액트 1개를 세 난이도로 도는 루프"를 완성한다.
- 아트 품질은 마지막에 올린다. 회색 박스(그레이박싱)로 재미부터 검증한다.

## 3. 개발 전략

### 전략 1: 수직 슬라이스 우선 (Vertical Slice First)
가로로 넓게(모든 시스템을 조금씩) 만들지 않고, **세로로 깊게** 하나의 완결된 경험을 먼저 만듭니다.

```
[수직 슬라이스 목표]
마을 → 필드 1개 → 몬스터 3종 → 보스 1종 → 드랍 → 장비 장착 → 강해짐 체감
이 루프가 "재미있다"고 느껴질 때까지 다른 콘텐츠를 늘리지 않는다.
```

### 전략 2: 데이터 주도 설계 (Data-Driven Design)
스킬, 아이템, 접사, 룬워드, 몬스터, 드랍 테이블은 전부 **데이터 애셋/테이블**로 정의합니다.

- 밸런스 수정에 코드 변경·리컴파일이 필요 없어야 함
- 스킬 1개 추가 = 데이터 행 추가 + 이펙트 연결 수준이 목표
- 이 구조가 갖춰지면 콘텐츠 물량전이 가능해짐

### 전략 3: 시스템 간 결합도 최소화
멀티플레이 확장을 대비해 처음부터 다음을 분리합니다.

- **게임 규칙(시뮬레이션)** ↔ **표현(이펙트/사운드/UI)**
- 캐릭터 스탯 계산은 순수 함수처럼: `(기본스탯 + 장비 + 스킬 + 정복자) → 최종스탯`
- 저장 데이터는 버전 필드를 포함한 직렬화 구조로 시작

### 전략 4: 밸런스는 공식으로
디아블로2의 검증된 수치 구조를 참고 기준으로 삼습니다.

- 몬스터 체력/피해량은 `기본값 × 난이도 계수 × 레벨 계수` 공식화
- 드랍률은 트레저 클래스(계층형 드랍 테이블) 방식
- 스프레드시트로 레벨 1~50 성장 곡선을 먼저 설계한 뒤 데이터에 반영

## 4. 리스크와 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 범위 폭발 (기능 욕심) | 완성 실패 | 마일스톤마다 "제외 목록" 재확인, 1액트 완결 원칙 |
| 타격감 부족 | 핵심 재미 상실 | 수직 슬라이스 단계에서 히트스톱·넉백·사운드 집중 검증 |
| 밸런스 붕괴 | 파밍 동기 상실 | 공식 기반 설계 + 치트 콘솔로 빠른 반복 테스트 |
| UE5 학습 곡선 | 일정 지연 | GAS 등 검증된 프레임워크 채택, 샘플(Lyra, ARPG 템플릿) 참고 |
| 아트 리소스 부족 | 비주얼 품질 저하 | 마켓플레이스 애셋 활용, 톤앤매너 일관성으로 커버 |

## 5. 성공 기준 (1차 릴리스)

- [ ] 신규 플레이어가 튜토리얼 없이 10분 안에 핵심 루프를 이해한다
- [ ] 캐릭터 1개로 노말 난이도 클리어까지 6~10시간 분량
- [ ] 두 캐릭터의 플레이 감각이 명확히 다르다 (근접 vs 원거리 캐스터)
- [ ] 만렙 후에도 정복자 + 룬워드 파밍으로 20시간 이상 플레이 동기 유지
- [ ] 세이브/로드가 안정적이고 아이템 로스가 없다
