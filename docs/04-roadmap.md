# 04. 개발 로드맵

수직 슬라이스 우선 전략에 따라 6개 마일스톤으로 진행합니다.
각 마일스톤은 **플레이 가능한 상태**로 끝나야 하며, 완료 기준(DoD)을 만족해야 다음으로 넘어갑니다.

## M0. 기반 구축

**목표**: UE5 프로젝트 골격 + 조작 가능한 캐릭터

- UE5 프로젝트 생성, C++ 모듈/폴더 구조 셋업 (docs/03 구조 반영)
- GAS 초기 셋업: AbilitySystemComponent, 기본 AttributeSet (생명력/마나/힘/민첩/활력/에너지)
- 쿼터뷰 카메라 + Enhanced Input 클릭 이동
- 그레이박스 테스트 맵
- 치트 콘솔 뼈대

**DoD**: 캐릭터가 클릭으로 이동하고, 콘솔로 스탯을 조작하면 AttributeSet에 반영된다.

## M1. 전투 수직 슬라이스 — "때리는 재미"

**목표**: 전사 1캐릭터로 핵심 전투 루프 검증

- 전사 기본 공격 + 스킬 3개 (강타/회전베기/도약공격) — GAS 어빌리티로 구현
- 몬스터 3종 (근접 졸개, 원거리, 돌진형) — BT 기반 AI
- 피해 계산 파이프라인 (명중/피해/저항), 사망/리스폰
- 타격감 1차: 히트 이펙트, 히트스톱, 넉백, 사운드
- 몬스터 스포너 + 오브젝트 풀링

**DoD**: 몬스터 무리를 스킬로 쓸어담는 것이 "재미있다"고 느껴진다. (내부 플레이테스트로 판정)

## M2. 아이템 & 드랍 — "줍는 재미"

**목표**: 파밍 루프의 뼈대

- 아이템 데이터 구조 (Base + Instance), 격자 인벤토리 + 장비창
- 접사 생성기 + 매직/레어 굴림
- 트레저 클래스 드랍 시스템 + 지면 드랍 표시 (이름표/색상)
- 장비 장착 → GameplayEffect 스탯 반영
- 물약/벨트, 골드, 마을 NPC 상점 최소 구현
- 드랍 시뮬레이터 (자동화 테스트)

**DoD**: 몬스터를 잡아 더 좋은 장비를 줍고 강해지는 체감이 명확하다. 드랍 통계가 설계 수치와 일치한다.

## M3. 성장 시스템 — "키우는 재미"

**목표**: 스킬트리 완성 + 두 번째 캐릭터

- 경험치/레벨업 + 스탯 수동 분배 UI
- 스킬트리 시스템: 3계열 트리 UI, 포인트 투자, 레벨/선행 게이트, **시너지 계산**
- 전사 스킬트리 전체 (24~30개) 데이터 정의 및 구현
- **원소술사 추가**: 3계열 스킬트리 전체, 원거리 캐스터 조작감
- 세이브/로드 1차 (캐릭터 슬롯)

**DoD**: 두 캐릭터가 레벨 1→25까지 서로 다른 빌드로 육성 가능하고, 세이브/로드가 안정적이다.

## M4. 캠페인 & 난이도 — "완결된 게임"

**목표**: 액트 1개 분량의 완결된 캠페인 + 3난이도

- 지역 3~4개 (마을 → 필드 → 던전 → 보스) + 웨이포인트
- 보스 2종 (중간 보스 + 액트 보스, 패턴 전투)
- 메인 퀘스트 라인 + 리스펙 보상
- 난이도 3단계 (노말/악몽/지옥): 몬스터 스케일링, 저항 페널티, ilvl 상승
- 몬스터 종류 확충 (10종+, 챔피언/유니크 몬스터 변형)

**DoD**: 노말 클리어 6~10시간, 클리어 후 악몽으로 재도전하는 루프가 돌아간다.

## M5. 엔드게임 — "끝없는 재미"

**목표**: 룬워드 + 정복자로 장기 플레이 동기 완성

- 룬 12종 드랍 + 3:1 합성, 소켓 시스템
- 룬워드 레시피 10종+ (판정/발동/표시)
- 유니크 아이템 15종+
- 정복자 시스템: 만렙 전환, 4분류 보드, 계정 공유
- 스태시 (계정 공유 창고), 도박 NPC
- 매직 파인드 파이프라인 완성

**DoD**: 만렙 캐릭터가 룬워드 완성과 정복자 성장을 목표로 파밍을 계속할 이유가 있다.

## M6. 폴리싱 & 릴리스 준비

**목표**: 품질 마감

- 밸런스 패스 전체 (성장 곡선, 드랍률, 보스 난이도)
- 아트/사운드 폴리싱: 톤앤매너 통일, 스킬 이펙트 2차, BGM/앰비언트
- UI/UX 개선: 툴팁(아이템 비교), 단축키 안내, 옵션(해상도/키 설정)
- 성능 최적화 패스 (60fps 목표 검증)
- 버그 픽스, 세이브 마이그레이션 검증

**DoD**: docs/01의 "성공 기준" 5개 항목 전부 충족.
