# 02. 핵심 시스템 설계

## 1. 캐릭터 (시작 2종)

### 1.1 전사 (Warrior) — 근접 물리
디아블로2의 바바리안 포지션. 근접 밀착 전투와 높은 생존력.

- **주 자원**: 분노(Fury) — 평타/피격으로 충전, 스킬로 소모
- **플레이 감각**: 적진 한가운데로 뛰어들어 광역기로 쓸어담는 묵직함
- **스킬 계열 3종**:
  | 계열 | 컨셉 | 대표 스킬 |
  |------|------|----------|
  | 무기술 (Arms) | 단일/광역 물리 피해 | 강타, 회전베기, 도약공격, 처형 |
  | 전장의 함성 (Warcries) | 버프/디버프 오라 | 전투의 함성(공격력), 위압(적 약화), 불굴(방어) |
  | 투지 (Fortitude) | 생존/반격 패시브 | 피의 갈증(흡혈), 철벽, 복수(반격) |

### 1.2 원소술사 (Elementalist) — 원거리 마법
디아블로2의 소서리스 포지션. 유리대포형 원거리 캐스터.

- **주 자원**: 마나(Mana) — 시간 회복, 물약/스탯으로 보충
- **플레이 감각**: 거리를 유지하며 화면을 뒤덮는 원소 마법의 화력
- **스킬 계열 3종**:
  | 계열 | 컨셉 | 대표 스킬 |
  |------|------|----------|
  | 화염 (Fire) | 고화력 광역 + 지속 피해 | 화염구, 운석, 불기둥, 발화 |
  | 냉기 (Cold) | 둔화/빙결 제어 | 얼음화살, 눈보라, 서리 신성, 빙갑 |
  | 번개 (Lightning) | 높은 편차의 폭딜 + 연쇄 | 번개, 연쇄 번개, 정전기장, 텔레포트 |

### 1.3 공통 스탯 구조 (디아블로2 방식)
레벨업당 스탯 포인트 5 지급, 4대 스탯에 수동 분배.

| 스탯 | 효과 |
|------|------|
| 힘 (STR) | 물리 피해 증가, 장비 착용 요구치 |
| 민첩 (DEX) | 명중률, 방어율, 일부 장비 요구치 |
| 활력 (VIT) | 생명력, 기력 |
| 에너지 (ENE) | 마나, 마나 회복 |

- 최대 레벨: **50** (이후 정복자 시스템으로 전환)
- 리스펙: 액트 클리어 보상으로 난이도당 1회 (선택의 무게 유지)

## 2. 스킬트리 시스템

### 2.1 구조
- 캐릭터당 3계열, 계열당 8~10개 스킬 = **캐릭터당 총 24~30개**
- 레벨업당 스킬 포인트 1 지급 (레벨 50 = 49포인트 → 전체의 일부만 투자 가능)
- 스킬당 최대 20레벨 투자 (하드 포인트)

### 2.2 해금 조건 (디아블로2 방식)
- **레벨 게이트**: 스킬별 요구 캐릭터 레벨 (1 / 6 / 12 / 18 / 24 / 30 티어)
- **선행 스킬**: 트리 상위 스킬에 최소 1포인트 필요

### 2.3 시너지 시스템 (핵심 차별화 재미)
디아블로2 1.10 패치의 시너지를 채택합니다. **다른 스킬에 투자한 하드 포인트가 주력 스킬을 강화**하는 구조로, "1포인트씩 넓게" vs "시너지 집중" 빌드 고민을 만듭니다.

```
예) 화염구 최종 피해 = 기본 피해 × (1 + 0.16 × 발화 포인트 + 0.16 × 운석 포인트)
```

- 시너지는 하드 포인트만 계산 (장비의 +스킬 레벨은 미포함 → 장비 가치와 분리)
- 스킬별 시너지 2~3개, 개당 +8~16% 계수

### 2.4 +스킬 장비와의 상호작용
- 장비의 `+N 모든 스킬`, `+N 화염 계열` 접사는 소프트 레벨로 합산
- 하드 20 + 장비 보정으로 실효 레벨 30+ 도달이 엔드게임 목표 중 하나

### 2.5 데이터 설계 (UE5)
```
DataTable: DT_Skills
- SkillId, Class, Tree, Tier, RequiredLevel, PrereqSkillIds[]
- MaxHardPoints, ResourceCost(레벨별 곡선), Cooldown
- DamageType, BaseDamage(레벨별 곡선), Synergies[{SkillId, PerPointBonus}]
- GameplayAbilityClass (GAS 어빌리티 클래스 참조), Icon, FX 레퍼런스
```

## 3. 아이템 & 룬워드 시스템

### 3.1 아이템 등급
| 등급 | 색상 | 특징 |
|------|------|------|
| 일반 (Normal) | 흰색 | 접사 없음, 소켓 가능 → **룬워드 베이스** |
| 매직 (Magic) | 파란색 | 접두사 1 + 접미사 1 |
| 레어 (Rare) | 노란색 | 접사 3~6개 랜덤 |
| 유니크 (Unique) | 금색 | 고정 디자인의 시그니처 아이템 |
| 룬워드 (Runeword) | 주황색 | 소켓 일반템 + 룬 조합으로 제작 |

### 3.2 접사(Affix) 시스템
- 접두사(Prefix) 풀 + 접미사(Suffix) 풀에서 아이템 레벨 기반 추첨
- 접사 예: `+N~M 화염 피해`, `+N% 공격속도`, `+N 스킬 레벨`, `N% 마법 아이템 발견율(MF)`
- **아이템 레벨(ilvl)** 이 접사 티어 상한 결정 → 고난이도 파밍 동기

### 3.3 룬 & 룬워드 (1차: 룬 12종, 룬워드 10종+)
- 룬은 낮은 확률 드랍, **3:1 상위 합성** 가능 (엘 3개 → 엘드 1개)
- 룬 단독 삽입 시 개별 옵션, **정확한 순서로 소켓에 넣으면 룬워드 발동**
- 룬워드는 베이스 아이템 종류 제한 (예: "강철" = 검/도끼/철퇴 전용)

```
예시 레시피 (1차 구현 목표)
- 강철 (Tir + El, 무기 2소켓): 공속 +25%, 최소피해 +3, 명중 +50, 시야 +1
- 은둔 (Nef + Lum, 방패 2소켓): 방어 +30%, 냉기저항 +30%, 에너지 +10
- 지혜 (Ort + Sol + Ith, 투구 3소켓): +1 모든 스킬, 마나회복 +15%, MF +25%
- 절정기: 4~5소켓 + 고급 룬 레시피 (엔드게임 파밍 목표)
```

- **설계 의도**: 일반(흰색) 아이템에 가치 부여 + 룬 파밍이라는 장기 목표 제공

### 3.4 드랍 시스템 — 트레저 클래스
계층형 드랍 테이블로 몬스터별 드랍을 정의합니다.

```
몬스터 → TC 참조 → [무기TC(30%) | 방어구TC(30%) | 룬/보석TC(10%) | 골드(20%) | NoDrop(10%)]
→ 하위 TC 재추첨 → 베이스 아이템 결정 → 등급 판정(유니크>레어>매직) → 접사 굴림
```

- 보스/챔피언은 NoDrop 감소 + 등급 판정 보너스
- MF(매직 파인드) 스탯이 등급 판정 확률에 체감 곡선으로 반영

## 4. 정복자 (Paragon) 시스템

만렙(50) 도달 이후의 무한 성장 축. 디아블로3 패러곤을 참고하되, **선택의 재미**를 강화합니다.

### 4.1 기본 구조
- 레벨 50 이후 획득 경험치는 **정복자 경험치**로 전환
- 정복자 레벨업마다 **정복자 포인트 1** 지급 (레벨 무제한, 요구 경험치 점증)
- 정복자 레벨은 **계정 공유** — 새 캐릭터도 혜택 (부캐 육성 동기)

### 4.2 정복자 보드 (4분류 로테이션 분배)
포인트는 4개 카테고리에 순환 분배(강제 로테이션)하여 한 스탯 몰빵을 방지합니다.

| 카테고리 | 노드 예시 (노드당 상한 50) |
|----------|--------------------------|
| 공격 | 피해 +0.5%, 공격속도 +0.2%, 치명타 확률 +0.1%, 치명타 피해 +1% |
| 방어 | 생명력 +0.5%, 방어도 +0.5%, 모든 저항 +0.2, 피해 감소 +0.1% |
| 자원 | 자원 최대치 +0.5%, 자원 회복 +0.3%, 쿨다운 감소 +0.1%, 이동속도 +0.2% |
| 유틸 | MF +0.5%, 골드 획득 +1%, 경험치 +0.5%, 물약 효과 +0.5% |

### 4.3 성장 상한 설계
- 정복자 총 기여도는 최종 캐릭터 파워의 **15~25%** 목표 (아이템이 주역이어야 함)
- 노드당 상한 + 점증 경험치로 초반 빠른 성취 → 후반 완만한 성장 곡선

### 4.4 엔드게임 루프와의 연결
```
만렙 도달 → 지옥 난이도 파밍 → 룬/유니크 드랍 + 정복자 경험치
→ 룬워드 제작 & 정복자 성장 → 더 효율적인 파밍 → (반복)
```

## 5. 지원 시스템 (1차 범위 내 필수)

- **인벤토리**: 격자(가로세로 칸 차지) 방식 — 테트리스식 공간 관리도 게임의 일부
- **스태시**: 마을 공유 창고 (계정 공유 → 부캐에 룬 전달)
- **물약/벨트**: 벨트 슬롯에 물약 퀵슬롯 (1~4키)
- **마을 NPC**: 상점(구매/판매), 수리, 도박(미감정 아이템 구매)
- **웨이포인트**: 지역 간 빠른 이동 + 파밍 러닝 시작점
- **난이도 3단계**: 노말/악몽/지옥 — 클리어 시 다음 난이도 해금, 몬스터 레벨·저항 상승, 악몽부터 저항 페널티(-40/-100)
- **세이브**: 로컬 저장, 캐릭터별 슬롯 + 계정 공유 데이터(스태시, 정복자) 분리
