# 07. M1 셋업 가이드 — 전투 수직 슬라이스

M1 코드가 저장소에 포함되어 있습니다. M0 셋업(docs/05)을 마친 상태에서 아래만 추가하면
전투 루프를 플레이할 수 있습니다. 모든 것이 그레이박스(엔진 기본 캡슐/구체 메시)로 동작하며,
애니메이션·이펙트 애셋 없이 검증 가능합니다.

## 1. 에디터 추가 작업 (최초 1회)

> **참고: 1.1~1.3은 이제 선택 사항입니다.** 애셋 미지정 시 C++이 기본 입력
> (우클릭 공격, Q/W/E)을 자동 생성하고, 맵에 스포너가 없으면 게임모드가
> 자동 배치합니다. 키 커스터마이즈가 필요할 때만 아래를 진행하세요.

### 1.1 입력 애셋 추가
`Content/Input/` 에 Input Action 4개 생성 (전부 Value Type = Digital):

| 애셋 | 권장 키 | 용도 |
|------|---------|------|
| `IA_BasicAttack` | 마우스 오른쪽 버튼 | 기본 공격 |
| `IA_Skill1` | Q | 강타 |
| `IA_Skill2` | W | 회전베기 |
| `IA_Skill3` | E | 도약공격 |

`IMC_Default` 에 위 4개 매핑 추가.

### 1.2 컨트롤러 BP 갱신
`BP_ROHPlayerController` 클래스 디폴트에서 새 프로퍼티 4개에 IA 애셋 지정:
- Basic Attack Action / Skill1 Action / Skill2 Action / Skill3 Action

### 1.3 스포너 배치
`L_Sandbox` 맵에 **ROHMonsterSpawner** 액터를 배치 (Place Actors 패널에서 검색).
- 기본값: 졸개/사수/돌격병 3종 순환, 최대 6마리, 처치 5초 후 재스폰
- NavMeshBoundsVolume이 스포너 반경(800)을 덮는지 확인

## 2. 조작법

- **좌클릭**: 이동 (꾹 누르면 따라오기)
- **우클릭**: 기본 공격 — 적중 시 분노 +10
- **1 강타**: 분노 15 소모, 단일 대상 강타 + 넉백 (쿨 4초)
- **2 회전베기**: 분노 25 소모, 주변 전방위 타격 (쿨 6초)
- **3 도약공격**: 분노 20 소모, 커서 지점 도약 + 착지 광역 넉백 (쿨 8초)
- **E 상호작용**: 주변 드랍 습득 → 없으면 인벤토리 첫 장비 장착 (추후 NPC 대화 확장)

## 3. M1 완료 기준(DoD) 검증

1. 몬스터 3종이 서로 다르게 행동한다: 졸개(추적 근접), 사수(거리 유지 + 투사체), 돌격병(빠른 돌진)
2. 기본 공격으로 분노를 모아 스킬 3종을 돌리는 사이클이 동작한다
3. 빗나감이 발생한다 (명중 공식: 2·AR/(AR+DEF) × 레벨 보정, 콘솔 로그 Verbose)
4. 피격 시 생명력 감소, 0이 되면: 몬스터 → 쓰러진 뒤 소멸·재스폰 / 플레이어 → 3초 후 시작 지점 부활
5. 타격 시 히트스톱(짧은 멈칫)과 넉백이 느껴진다
6. **핵심 판정: "몬스터 무리를 쓸어담는 것이 재미있는가?"** — 아니라면 수치/연출을 조정하고 M2로 넘어가지 않는다 (docs/04)

치트로 빠른 검증:
```
ROHSetAttr Rage 100        ← 분노 채우기
ROHSetAttr Strength 100    ← 화력 실험
ROHDumpAttrs
```

## 4. M1에서 구현된 것 (코드 구조)

```
Source/ROH/
├── ROHGameplayTags            # 네이티브 태그 (피해/상태/쿨다운)
├── Combat/
│   ├── ROHCombatStatics       # 명중 굴림→저항 완화→피해 GE 파이프라인, 원뿔/반경 타겟팅, 넉백, 히트스톱
│   └── ROHProjectile          # 범용 투사체 (M3에서 원소술사도 재사용)
├── Abilities/
│   ├── ROHGameplayAbility     # 비용(분노/마나)/쿨다운(SetByCaller)/타격 피드백 훅
│   ├── ROHGameplayEffects     # 공용 피해 GE + 쿨다운 GE
│   ├── Warrior/               # 기본공격, 강타, 회전베기, 도약공격
│   └── Monster/               # 근접 공격, 원거리 투사체 공격
├── Character/
│   ├── ROHCharacterBase       # 팀/사망 처리/어빌리티 부여/그레이박스 비주얼
│   ├── ROHPlayerCharacter     # 전사 프리셋, 스킬 슬롯, 부활
│   └── ROHMonsterCharacter    # 몬스터 베이스 + 졸개/사수/돌격병
├── AI/ROHMonsterAIController  # 경량 추적/공격 AI (보스 BT는 M4)
└── World/ROHMonsterSpawner    # 유지 스폰 + 재스폰
```

### 의도적으로 M1에서 제외한 것
- 애니메이션/몽타주 (아트 단계에서 어빌리티에 연결)
- 오브젝트 풀링 (M2 물량 확충 시)
- HUD (체력/분노 바) — M2 아이템 UI와 함께
- 피해 파이프라인의 ExecutionCalculation 이관 (M2 장비 접사 도입 시)
