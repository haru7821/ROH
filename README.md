# Project ROH — 핵앤슬래시 ARPG

디아블로2에서 영감을 받은 싱글플레이 핵앤슬래시 ARPG 프로젝트입니다.
**언리얼 엔진 5(UE5)** 기반으로 개발합니다.

## 1차 목표 (싱글 모드)

- **싱글플레이 전용**으로 완결된 게임 루프 구현
- **2가지 시작 캐릭터** (근접 전사 / 원소 마법사)
- **스킬트리 시스템** — 캐릭터당 3계열, 시너지 기반 성장
- **룬워드 시스템** — 소켓 장비 + 룬 조합으로 강력한 아이템 제작
- **정복자(Paragon) 시스템** — 만렙 이후 무한 성장 엔드게임

## 개발 현황

- [x] **M0. 기반 구축** — UE5 프로젝트 골격, GAS 셋업(ASC/AttributeSet), 쿼터뷰 클릭 이동, 치트 콘솔
- [x] **M1. 전투 수직 슬라이스** — 전사 스킬 4종(분노 사이클), 몬스터 3종 AI, 명중/저항 피해 파이프라인, 사망/부활, 히트스톱/넉백, 스포너 ([가이드](docs/07-m1-setup-guide.md))
- [x] **M2. 아이템 & 드랍** — 접사 생성기, MF 체감 곡선 등급 판정, 계층형 트레저 클래스, 장비 장착 GE 반영, 물약/골드, 드랍 시뮬레이터+자동화 테스트 ([가이드](docs/08-m2-setup-guide.md))
- [ ] M3. 성장 시스템 (스킬트리 + 원소술사)
- [ ] M4. 캠페인 & 난이도
- [ ] M5. 엔드게임 (룬워드 + 정복자)
- [ ] M6. 폴리싱

## 개발 원칙

1. **데이터 주도 설계** — 스킬/아이템/몬스터는 코드가 아닌 데이터(JSON)로 정의
2. **수직 슬라이스 우선** — 얕더라도 끝까지 플레이되는 루프를 먼저 완성
3. **확장 가능한 구조** — 멀티플레이·추가 캐릭터를 염두에 둔 시스템 분리
